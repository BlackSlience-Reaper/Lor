# 有状态静态字段的生命周期登记表。tools/check_static_state.py 按 snapshots/static_fields.txt 核对：
# 可变静态字段，以及类型是集合、弱表、AsyncLocal、Random、RunScoped/CombatScoped 等可变容器的只读静态字段，
# 都必须在这里登记；删掉或改名的字段也要从这里删掉。
#
# 格式：字段全名<TAB>类别<TAB>子类<TAB>说明（写入点、复位点、对玩法的影响）
# 类别：
#   run       一局内的玩法状态。新增的优先用 RunScoped<T>，离开本局时由 RunLifecycle 复位。
#   combat    一场战斗内的玩法状态，或以战斗里的对象为键的表。新增的优先用 CombatScoped<TKey, TValue>。
#   instance  以某个对象为弱键的表，随键对象回收，与局、战斗无关。
#   harmless  不承载玩法状态，子类必填：
#             cache 缓存或只初始化一次的表；once 一次性初始化、注册标志；log 只为不重复记日志；
#             ui 表现层节点、播放与界面状态；settings 本地设置值；scope 作用域标记或调用深度；
#             registry 启动时的注册表或订阅；net 联机会话、消息交接。
# run / combat / instance 的子类写 -。类型是 RunScoped 的必须是 run，CombatScoped 的必须是 combat。
