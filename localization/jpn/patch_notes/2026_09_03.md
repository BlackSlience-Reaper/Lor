Library of Ruina v0.18.9を公開しました！以下はv0.18.7からの直接比較で、幻想体ページの強化、死んだ蝶の群れと黄昏の調整、完全開放戦の修正、ゲーム標準画面を使う常設の更新履歴入口を含みます。

[blue][b]コンテンツとバランス：[/b][/blue]

[b]幻想体ページ：[/b]
- [b]大鳥のページ[/b]を強化：
  - 「監視の目」のクールダウンを3ターン → 2ターンに短縮
  - 「永燃の灯」のクールダウンを7ターン → 6ターンに短縮
  - 「救済」の永続強壮を2 → 3に増加
- [b]蒼い星のページ[/b]を強化：
  - 「殉教」の混乱ダメージを4(6) → 7(9)に増加
  - 「贖罪」の混乱ダメージと追加HP損失の増加率を10% → 15%に増加
- [b]穿刺楽園のページ[/b]を強化：
  - 「萎縮した血翼」の反動を30% → 70%に増加
  - 「他者の視線」の追加ドローを3 → 4、次ターンのエナジーを2 → 3に増加
  - 「注目と集中」のダメージと混乱ダメージ増加率を30% → 40%に増加
- [b]渇望の心臓のページ[/b]を強化：
  - 「鼓動」の永続筋力を3 → 4に増加
  - 「渇望」の最大HP増加率を33% → 40%に増加
  - 「激しい鼓動」の筋力、忍耐、守護、迅速を5 → 8に増加
- [b]審判鳥のページ[/b]を強化：「傾いた天秤」の回復量を2 → 3、各ターンの発動上限を3回 → 4回に増加
- [b]オズマのページ[/b]を強化：「旧日の力」のアタックダメージ倍率を2倍 → 3倍に増加
- [b]沈黙の対価のページ[/b]を強化：
  - 「時間」のエナジーと追加ドローを1 → 2に増加
  - 「十三回目の鐘」のドローを1 → 2に増加
  - 「沈黙」の虚弱を24 → 48に増加
- [b]罰鳥のページ[/b]を強化：
  - 「罰」のHP損失倍率を8倍 → 9倍に増加
  - 「懲罰のくちばし」の筋力を2 → 5に増加
- [b]知恵を求める案山子のページ[/b]を強化：
  - 「収穫」の追加攻撃ダメージと混乱ダメージを9 → 10に増加
  - 「引き裂かれた知恵」の発動間隔を7枚 → 6枚に短縮し、得るエナジーを1 → 2に増加
- [b]熱心な木こりのページ[/b]を強化：
  - 「温かな心」の永続強壮を2 → 3に増加
  - 「心臓」のHP損失条件を24 → 20に減少
  - 「伐採」の強壮上限を6 → 8に増加

[b]敵：[/b]
- [b]死んだ蝶の群れ[/b]を調整：
  - 混乱耐性を20 → 10に減少
  - 「安らかに眠れ」を3回攻撃から2回攻撃へ変更し、1回ごとのダメージを1増加
- [b]黄昏[/b]を調整：
  - 「小喙」はカードを1枚プレイするたび、手札のランダムな1枚のコストをこのターン2増加
  - 「長臂」は防いだデバフを付与者へ反射
  - 「徘徊」のブロックを16 → 12、「傾いた秤」の罪を12 → 9、「懲罰」の罪1層あたり回復率を10% → 6%に減少
  - 「振り下ろす」「引っ掻く」「黒い森を守ろう」「傾いた秤」「懲罰」「みんなの平和」の一部ダメージを減少
- [b]偽りの王座[/b]を調整：「お遊びはここまで！！！」は1ターンの虚弱を999付与し、武装解除を削除

[b]完全開放戦：[/b]
- [b]文学の階完全開放戦[/b]を強化：「執念」の魂縛の鎖を1 → 2に増加
- 「超～特大プレゼント！！」「耐えられない！！！」「黒鳥の絶唱」を調整：攻撃ダメージが対象のブロックを上回る場合、群体攻撃の前にブロックの半分を除去
- 血の渇望フェーズ移行時、既存の通常出血を保持

[blue][b]ユーザー体験とインターフェース：[/b][/blue]

- MOD設定に[b]更新履歴を見る[/b]を追加し、ゲーム標準の更新履歴画面、スクロールバー、ページ移動、戻る操作を使用
- 各階の完全開放戦Bossマップアイコンに、それぞれの階の移動済み、未移動、輪郭色を適用
- カスタムメインメニューBGMと非戦闘BGMの相対音量を60%に統一
- 完全開放戦の低段階報酬説明に、ランダム強化されるカード枚数を表示
